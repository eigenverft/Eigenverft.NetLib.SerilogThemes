# Eigenverft.NetLib.SerilogThemes.Console

This non-packable console project is the local executable companion to the Serilog themes library. Its current scaffold prints a greeting; interactive theme examples will be documented when the theme sources are restored.

Run it from the repository root with:

```shell
dotnet run --project src/prj/Eigenverft.NetLib.SerilogThemes.Console/Eigenverft.NetLib.SerilogThemes.Console.csproj
```
